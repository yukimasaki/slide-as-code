# slide-as-code

発表用のスライドを、CSS・JavaScript・画像を埋め込んだ1つのHTMLファイルで作るエージェントスキルです。ビルドは不要で、ブラウザでそのまま開けます。

## スキルの使い方

エージェントに [skills/slide-as-code/SKILL.md](skills/slide-as-code/SKILL.md) を読ませ、「5分の発表用スライドを作って」のように依頼します。スキルのディレクトリを、使っているエージェントのスキル置き場から参照しても使えます。

スキルは、材料の確認、構成、HTMLの作成、表示の確認、出力先の報告までを扱います。配色や場面の演出は、話の中身に合わせて決めます。

## 出力先

Python 3で出力先を決めます。次のコマンドは資料のディレクトリを作り、`index.html` の絶対パスを標準出力に表示します。HTML自体は、そのパスに書き出してください。

```bash
python3 skills/slide-as-code/scripts/output_path.py --name example-talk
```

既定の保存先は `${XDG_DATA_HOME:-~/.local/share}/slide-as-code/<資料名>/index.html` です。作った資料はリポジトリに置きません。

出力先を変更する場合は、`${XDG_CONFIG_HOME:-~/.config}/slide-as-code/config.json` に `outputDir` を設定します。

```json
{
  "outputDir": "~/Documents/slides"
}
```

- `outputDir` は資料ごとのディレクトリを置く親ディレクトリです。上の設定なら `~/Documents/slides/example-talk/index.html` に出力します。
- パス先頭の `~` はホームディレクトリに展開します。絶対パスも使えます。相対パスと `$変数名` の展開には対応しません。
- `XDG_CONFIG_HOME` と `XDG_DATA_HOME` は、未設定または空なら既定値を使います。設定する場合は絶対パスを指定します。
- 設定ファイルがない場合や `outputDir` を省略した場合は、既定の保存先を使います。不正なJSONや空の `outputDir` はエラーとして報告します。
- ヘルパーはシンボリックリンクを解決し、Gitリポジトリ内の出力先を拒否します。資料名にはパス区切りや `.`・`..` を指定できません。既存のHTMLは変更しません。

`.gitignore` でも、資料のディレクトリ、HTML、画像、動画などの書き出しを除外します。

## 作り方の決まり

- CSS、JavaScript、画像をHTMLに埋め込み、外部ファイルの読み込みやブラウザの保存機能に依存しません。フォントはシステムフォントを使います。
- 固定サイズの舞台を `left: 50%; top: 50%` に置き、`translate(-50%, -50%) scale(k)` で画面に合わせます。
- キー、クリック、スワイプでページをめくれるようにし、現在のページ番号を表示します。
- `prefers-reduced-motion` を指定した閲覧者には、動きを止めた最終状態を表示します。
- 数字には出典と確認日を添えます。広い画面と狭い画面で全ページを確認し、確認できなかった項目は報告します。

## 作った資料を開く

出力先の `index.html` をブラウザで開きます。ファイルマネージャーから開くか、ブラウザの「ファイルを開く」で選べます。エージェントは、出力した絶対パスと開き方を報告して作業を終えます。
